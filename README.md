Sixty-two backend workflow endpoints. This repository documents the architecture and, more usefully, the trade-offs and the things that are not finished.

### How I work

**Cost is a design constraint.** Credit floors, batch caps and metered billing go into the specification, not into a post-mortem after the first surprise invoice.

**Guardrails before capability.** Nothing that touches a customer ships without an approval gate or a dry-run default. I write down what a system may *not* do before I make it able to do anything.

**I audit my own work and publish the result.** I would rather hold an honest list of my product's three worst problems than believe it is finished. That list is in the platform repository.

**Restraint.** I have deleted AI features that demoed well and shipped the boring deterministic version the customer actually asked for. I have unpublished my own working system when I found its economics were wrong.
